# Remove Duplicates In A Sorted Linked List

## Problem

You are given a **sorted** singly linked list. Implement a
`removeDuplicates` function that removes all duplicate elements from the
list, so that each value appears only once.

> **Note:** The function is called on the sorted list and must remove
> the duplicates in linear time and constant space.

## Constraints

- Time complexity: O(n)
- Space complexity: O(1)

## Sample Input

```
10
2 2 2 3 3 5 5 5 5 5
```

- Line 1: size of the list
- Line 2: elements of the list

## Sample Output

```
2 2 2 3 3 5 5 5 5 5
2 3 5
```

- Line 1: the list before removing duplicates
- Line 2: the list after removing duplicates
