# Merge Sort A Linked List

## Problem

You are given the head and tail of an **unsorted** singly linked list.
Implement a `mergeSort` function that returns a **new** linked list
containing all the elements of the given list in ascending order.

> **Note:** The original linked list must not change.

## Constraints

- O(n log n) time complexity required

## Sample Input

```
6
10 2 19 22 3 7
```

- Line 1: size of the list
- Line 2: elements of the list

## Sample Output

```
2 3 7 10 19 22
10 2 19 22 3 7
```

- Line 1: the sorted list
- Line 2: the original list (unchanged)
